# AI Short Drama Skill（AI 微短剧制作技能）

一个把"做短剧"从玄学变成可复用流水线的工作流集合。把调研结论沉淀成一份能直接用的 `SKILL.md`。

## 这是什么
- 一份生产级短剧制作 Skill（`SKILL.md`），覆盖从剧本到成片的 7 步流水线。
- 两份深度调研文档（`docs/`），分别讲"短剧创作能力地图"和"高星标开源项目方法论复盘"。

## 目录
```
ai-short-drama-skill/
├── SKILL.md                                   # 核心技能定义（7 步流水线 + 设计原则）
├── README.md                                  # 本文件
└── docs/
    ├── 短剧创作学习清单.md                      # 行业/剧本/工具/竖屏/投流/出海/合规
    └── GitHub短剧与AI技能学习汇报.md            # 开源项目方法论复盘
```

## 怎么用
1. 把 `SKILL.md` 放进你的 Agent / Cursor / Claude Code 的 skills 目录。
2. 对 Agent 说"帮我做一集 AI 短剧"，它会按 7 步流水线推进。
3. 关键在 **资产一致性** 与 **人类审核闸** —— 这是可看与可发的分水岭。

## 核心结论
> 短剧的技术已平权，**真护城河在四样机器替代不了的人类能力**：剧本节奏感 + 竖屏视听语言 + 投流 / 本地化商业嗅觉 + 合规红线意识。

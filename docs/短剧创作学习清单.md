# 短剧（微短剧）创作能力 · 我的学习清单

> 调研时间：2026-10-11 ｜ 调研方式：全网深度检索（行业报告、政策原文、创作者实战、工具测评）
> 定位：一份从"行业认知→剧本→工具→拍摄→变现→出海→合规"的闭环能力路线图，目标是让 AI 助手具备从 0 到 1 协助产出可上线短剧的实战能力。

---

## 0. 行业认知（先建立地图，避免瞎干）

**必须搞清楚的几个数字与事实：**
- [ ] 市场规模：2025 年破千亿，2026 年用户月活 **7.18 亿**（独立 App 3.35 亿 + 微信小程序 4.27 亿），已是全民内容形态。
- [ ] AI 化拐点：2026 Q1 全行业上线短剧约 12.8 万部，**AI 参与或主导占比 95%+**，单月新增近 5 万部。
- [ ] 成本结构：AI 制作成本仅为真人 **1/10**（精品 AI 仿真剧可控制在 20 万内 vs 真人 150 万）；但**投流占总流水约 70%**，是最大成本项。
- [ ] 盈利现实：大盘日投流消耗 **1.5–1.7 亿元**；成熟投流团队 ROI 仅 1.03–1.07（微利），普通项目 ROI < 0.8 即亏损；千次播放收益从 2025 下半年的 ~60 元跌到 15–30 元。
- [ ] 关键结论：**技术已平权，内容理解（剧本+视听语言+审美）才是稀缺壁垒。** 别沉迷工具参数，学点技术但别沉迷技术。

**核心认知（避坑）：**
- [ ] "堆量"模式有尽头——AI 漫剧每 1000 部只有 1 部跑出来（爆款率 < 0.1%）。行业从"重量"转向"重质"。
- [ ] AI 是工具不是目的，内容核心还是人。全面 AI 化、放弃人工把关的公司已用失败证明这一点。
- [ ] 最稀缺的人才：**AI 导演**（既要懂传统视听语言/轴线规则，又要懂 AI 模型特性与叙事节奏）、既懂投流又懂内容的人（年薪 50 万抢不到）。

## 1. 剧本创作（核心护城河，最难被 AI 替代）

**单集节奏万能公式（1–2 分钟/集，最优 90 秒）：**
- [ ] **黄金 3 秒钩子**（生死线）：直接冲突（掌掴/下跪/对峙）/ 强悬念（枪指头/DNA 单）/ 极致反差（婚礼变葬礼）。**绝无慢开场。**
- [ ] **10 秒入戏**：交代核心矛盾 + 人物关系 + 主角目标，无废话铺垫。
- [ ] **30 秒反转**：第一次小情绪高潮，走"压→爆→压→爆"曲线，不让观众走神。
- [ ] **中段高密度**（50–80 秒）：每 15–20 秒一个小冲突/小爽点/小悬念；台词短、碎、狠；节奏快→慢→快。
- [ ] **结尾 10 秒强钩子**（必留）：卡在最高潮戛然而止黑屏。三类钩子——悬念钩 / 危机钩 / 反转钩。钩子力度必须 > 本集所有冲突。

**全剧长线节奏（20–100 集常见）：**
- [ ] 开篇 1–5 集：极速建世界观 + 立人设 + 抛主线 + 第 3 集小爆。
- [ ] 中段：三集一小爆、五集一大爆，爽点虐点交替，避免审美疲劳。
- [ ] 高潮段：终极冲突 + 连环反转 + 最大爽点。
- [ ] 收尾：完整结局 + 彩蛋 + 续集伏笔。

**台词与画面铁律：**
- [ ] 台词：每句 **≤ 10–15 字**，说完就切，不留气口；多短句/反问/命令句，少陈述句。
- [ ] 画面：要"演"出来不是"说"出来。能用动作表现的别用台词（"攥紧拳头指甲嵌进掌心" > "我太生气了"）。
- [ ] 信息：每集只讲一件事，主线唯一，副线 ≤ 1 条；少闪回少回忆。

**主流题材赛道：** 霸总 / 复仇 / 甜宠 / 虐恋 / 逆袭 / 现实题材（政策鼓励，流量红利）。

**实操三步法（新人必做）：**
1. [ ] 拆 3 部同赛道爆款，记三件事：每集事件 / 推进剧情还是造爽点 / 卡点设哪。
2. [ ] 先写全剧大纲（四阶段结构），定爽点/反转/伏笔位置，再细化到秒。
3. [ ] 用 AI 出初稿你改（效率翻 10 倍），但节奏骨架必须自己掌控。

## 2. AI 工具链（降本增效的武器库）

**一站式创作平台：**
- [ ] 即梦 AI（字节 / Seedance 2.0）：剧本→分镜→视频→配音剪辑一站式，音画同步，商用低至 1 元/秒。
- [ ] 可灵 AI（快手）：角色一致性好，适合系列剧；O1 版人物记忆与跨镜头一致性质的飞跃。
- [ ] 万镜一刻、小云雀 AI（新手友好）、OiiOii（7 个 AI Agent 模拟完整动画流程）。

**垂直工具分层掌握：**
- [ ] 剧本/分镜：豆包、Claude、Qwen、Kimi、Kimi —— 让大模型写剧本、拆分镜、生成提示词。
- [ ] 视频生成：可灵（角色一致性）、即梦（音画同步）、商汤 Seko 2.0（支持 100 集连续剧）、ComfyUI + LTX（本地免费、四宫格分镜直出 12 秒，显卡要求高）。
- [ ] 配音：鱼声（最简单）/ GPT-SoVITS / CosyVoice / ElevenLabs（支持声音克隆、情感控制）。
- [ ] 剪辑合成：剪映（2026 内置 AI 文字成片、数字人、声音克隆，与即梦打通，短剧后期最顺）。

**开源/低成本方案（跑通感知用）：**
- [ ] huobao-drama：十分钟出成片，零基础试水。
- [ ] oowaoo：网文 IP 直转短剧强项。
- [ ] Moyin Creator：工业化量产多集。

**关键认知：** 全自动 = 对画面细节控制力有限。要画质和人物一致性，回头看 Moyin Creator 或自搭 ComfyUI 工作流。

## 3. 竖屏视听语言（拍摄与分镜规范）

**基础规范（9:16 竖屏）：**
- [ ] 面部特写占 **50%+**，胸部以上为主；横屏的全身/并排对话在竖屏里要改成前后站位/正反打。
- [ ] 景别体系：远景 → 全景 → 中景（腰以上）→ 近景（胸以上）→ 特写（头）→ 大特写（眼/手）。
- [ ] 镜头运动：**固定为主**，慎用推拉摇移（手机端易晕）；若运动标"缓慢水平微移"。
- [ ] 构图：中心聚焦 / 黄金分割，人物眼睛在上方 1/3；利用纵深（走廊、楼梯）制造空间。

**镜头语言的情绪语法：**
- [ ] 仰拍 = 权力/压迫（拍反派/霸总）；俯拍 = 弱势/可怜（拍受委屈主角）。
- [ ] 越肩镜头 = 双人对话标准机位，营造对峙与压迫感。
- [ ] 手部特写（签文件/握拳/摔杯子）比语言更有冲击力。

**灯光与参数：**
- [ ] 三点布光：主光 45° + 补光 90° + 轮廓光 120°；色温控制（暖光温馨 / 冷光压抑）。
- [ ] 拍摄参数：4K/24–30fps、Log 模式、特写大光圈 f/1.8–2.8、对话 f/2.8–4.0。
- [ ] 收音：无线领夹麦，对话距离 30–50cm。

**分镜标准化模板（每镜必标）：** 镜号 / 时长 / 景别 / 画面内容 / 人物状态 / 镜头运动 / 台词 / 音效 / 竖屏适配备注。

**转场：** 硬切为主；黑屏转场（冲突爆发后黑屏 1 秒再切钩子）留白增强冲击；少用淡入淡出/叠化/空镜。

**预算意识写剧本：** 全剧 80% 场景 [$]（室内 2 人对白）、15% [$$]、5% [$$$]（高潮打脸名场面）。一个实景多用（白天=温馨卧室，夜晚=昏暗卧室）。

## 4. 投流与变现（赚钱的关键）

**四大变现模式：**
- [ ] **IAA**（免费广告流，份额 62.4%）：红果/河马，看 15 秒激励广告解锁；平台按播放/完播/时长分账，头部优质剧分成 70–80%。适合中小团队稳现金流。
- [ ] **IAP**（付费充值，份额 55.8%）：微信/抖音小程序，首充卡点、关键情绪转折；抖音/红果优质剧最高 90% 分成，单部保底 360–500 万。头部效应极强。
- [ ] **混变**（IAA+IAP）：2026 主流高爆发组合。
- [ ] **电商带货 / 品牌定制**："看剧-种草-下单"闭环（快手打通美团/京东）；品牌从赞助方变共研方。

**平台格局（分发渠道）：**
- [ ] 独立 App：红果（日活 1.68 亿 / 月活 3.68 亿，断崖领先）、河马。
- [ ] 短视频：抖音（算法孵化爆款）、快手（下沉+电商闭环）。
- [ ] 微信小程序：用户量最大单一入口（超 5 亿），社交裂变强、合规成本可控；腾讯"绿泡泡"统一出口，100% 收入激励。
- [ ] 长视频：爱优腾芒走横屏精品化，分账周期拉长至 3 年。

**投流关键岗位与指标：**
- [ ] 投流手 + 编剧 + 数据分析 = 核心铁三角；懂内容又懂算法的人最稀缺。
- [ ] 算法偏好：完播率 > 点赞 > 评论 > 转发；素材日更 8–10 套。
- [ ] 分账利润模拟：用 ROI 预设（及格 1.05 / 现象级 1.65）、CAC、分账比例测算回本周期。

## 5. 出海与本地化（增量蓝海，利润率最高）

**平台与模式：**
- [ ] 海外头部：ReelShort（中文在线）、DramaBox（点众）、ShortMax（九州）、Melolo（字节/东南亚免费）、FreeReels（昆仑万维）。
- [ ] 双模式：**北美/西欧**高 ARPU → 付费解锁（IAP）；**东南亚/拉美**价格敏感 → 免费广告 + 低价升级。
- [ ] 底层逻辑：把"核心配方"（生产流程/节奏模板/测试基建/变现架构）与"体验层"（选角/语言/文化元素）分离——全球本土化操作系统。

**本地化不是翻译，是"前 3 秒在地化"：**
- [ ] 开场钩子落在当地语感；文化参照与社会关系要调；CTA 贴平台支付话术。
- [ ] 语言优先级分层铺：英语 → 西语（拉美+西班牙 5 亿）→ 印尼/马来 → 葡语（巴西 2 亿）→ 阿语（中东高付费）。先打透高 ARPU，再长尾覆盖。
- [ ] "一鱼多吃"多平台分发：同剧多语种铺到 ReelShort/DramaBox/NetShort/TikTok/自有 App，建独立账号矩阵。

**AI 译制降本（产能引擎）：**
- [ ] 腾讯云 MAIS SOP：100 集 × 9 语种 48 小时交付，单集约 2.7 元，成本降至人工 1/10。
- [ ] 马栏山智能译制中心：120 分钟微短剧 4–5 小时完成，准确率 > 95%，支持 40 门语种。
- [ ] 配音做"分层"：钩子集用高情感克隆，长尾集用音色 ID 控边际成本；沉淀角色多语种"音色 ID"为公司资产。
- [ ] 本土剧占比已从 2025 <20% 升至 2026 年 1–2 月的 36%——"翻得好"吃掉更多份额。

## 6. 合规与备案（红线意识，必须前置）

**《微短剧发展管理办法》（广电总局令第 16 号，2026-09-01 施行，八章五十四条）：**
- [ ] 定义：单集时长 **少于 20 分钟**，主题主线明确、情节连续完整、人物突出。包装成"剧情号/故事号"也算。
- [ ] 分类分层：**一类**（投资额度较大 / 涉及政治·军事·外交·国安·统战·民族·宗教·司法·公安等特殊题材）；**二类**（一般题材、投资相对不大）；**三类**（低投资一般题材）。
- [ ] 先备案后开机、持证上岗：一类/二类需《微短剧发行许可证》或批准文件；三类由播出单位审核并标注节目编号。所有上线剧须持许可证或完成报备，片头标备案号。
- [ ] 内容红线（第二十五条 11 类禁止）：危害国家统一、煽动民族仇恨、侵害未成年人、宣扬淫秽/赌博/吸毒/拜金/奢靡、散布虚假信息、教唆犯罪等。
- [ ] **AI 生成微短剧必须在每集明显位置添加提示标识。**
- [ ] 未成年人保护、价值观导向（抵制"炫富拜金""颜值正义""丛林法则"等不良导向）。
- [ ] 算法治理：不得用诱导沉迷、过度消费的算法模型；优先推荐优质内容。

**创作侧落地：**
- [ ] 剧本阶段嵌入合规把关 + AI 敏感词预警，把合规从后期补救前移到立项孵化。
- [ ] 三类剧投资门槛提升：原重点 100 万→300 万，普通 30 万→100 万（2026-01-01 起），引导精品化。

## 学习路径与里程碑（路线图）

| 阶段 | 周期 | 目标 | 验收标准 |
|------|------|------|----------|
| **一、行业认知** | 1–2 周 | 吃透市场/政策/商业模式，建立"技术平权、内容稀缺"的判断 | 能独立讲清 IAA/IAP 区别、管理办法分类、投流 ROI 逻辑 |

| **六、出海/精品** | 3 月+ | 本地化流水线 or 精品化冲刺 | 多语种版本 / 一部精品立项 |

### 一句话总结
短剧这门"skill"的真壁垒不在 AI 工具（已平权），而在 **剧本节奏感 + 竖屏视听语言 + 投流/本地化商业嗅觉 + 合规红线意识** 这四样机器替代不了的人类能力。学习清单的顺序就按"先懂行 → 写好本 → 用顺工具 → 拍出片 → 卖出去 → 走出去/做精品"展开。
